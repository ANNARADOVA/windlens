WindLens estimates missing turbine production from a behaviorally selected reference turbine, then checks it against available evidence before you rely on it.

Upload your own outage — or keep reading the live BayWa record below

What to upload: every broken turbine's own file, at least one other turbine's file to use as a reference, and — for a financial figure — that broken turbine's own power curve file. More reference files improve the match; power-curve files just need to each be named for their own turbine (e.g. T2_power_curve.xlsx). You can upload several broken turbines at once — drop everything into the one box together and we automatically sort out which file is which.

No files on hand? T2 (target), O1 (reference), T2's power curve — download all three, then select all three together in the one box below.

This runs a live, separate calculation on whatever you upload — it replaces the result view below with your own run. The real BayWa T3 submission underneath is never changed by this.

File format details

Wind-data columns are either timestamp_utc,turbine_id,wind_speed_ms (canonical) or timestamp,turbine_name,wind_speed (BayWa raw); power-curve columns are wind_speed,power or bin_center_ms,mean_power_kw.

We auto-detect every qualifying gap on every uploaded turbine — including a turbine with two or more separate outage periods in its history, which each get their own result below. A gap needs at least 3 consecutive missing readings to auto-detect (shorter dropouts are common on healthy turbines too and aren't treated as outages); for a dropout shorter than that, use the manual window fields below instead.

Full methodology and limitations
Reconstruction

—

vtarget(t) ≈ a + b · vreference(t) — b is set so the predicted wind matches the target's own variance (std(target) / std(reference), signed by their correlation), not ordinary least-squares; a is fit from the pre-outage overlap so the line passes through both turbines' average readings. Plain least-squares regression under-predicts energy once pushed through a power curve; matching variance instead avoids that.

Energy calculation

—

Lost energy = Σ P(vtarget(t)) · Δt — P(·) is the target turbine's own pre-outage power curve, Δt is the reading interval (10 minutes for BayWa).

Limitations
    Other methods we considered
    • Direct power regression (reference turbine's power output → target's power output directly) — excluded for the real BayWa submission because no BayWa source file contains a power column; it remains a same-farm comparison method in the external validation below.
    • Naive averaging of other turbines in the uploaded dataset (no wind reconstruction, no fitting) — competitive at same-farm distance, but loses clearly once turbines are genuinely far apart, so it is not the shipped method.
    • Multi-turbine blend (averaging several reference turbines instead of one) — ties or slightly underperforms a single well-chosen reference at real cross-farm distance; kept as a documented alternative, not shipped as the default.

    Wind-first single-reference reconstruction is what shipped because it is the only method tested that stays reasonable both at same-farm and at real cross-farm distance.

    What we'd build next
    • A calibrated uncertainty interval for the real BayWa pipeline, once enough held-out BayWa data exists to build one; this record's gate is marked "not evaluated" until then.
    • Automatic outage-cause classification, so you don't have to separately confirm whether a gap was a sensor fault or a real mechanical outage before trusting the estimate.
    • Support for a genuine neighbouring-farm scenario once two real, nearby, overlapping farms are available to test against (today's nearest proxy is ~399 km apart).
    • Before the real BayWa data arrived, we explored validating this method on public wind farms at a range of target-reference distances, and on how a turbine-location registry (geographic proximity, not just behavioral correlation) might change reference selection — both remain open directions, not part of this submission's evidence.
