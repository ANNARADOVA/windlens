# WindLens BayWa PowerPoint deck

## Goal

Create a seven-slide editable PowerPoint deck that preserves the archived WindLens methodology carousel content while translating its dark, evidence-first visual language into BayWa-inspired presentation styling.

## Slide structure

1. Detect — find the gap and distinguish data evidence from outage cause.
2. Select — choose a reference turbine using pre-outage behavior.
3. Estimate — reconstruct wind, then convert to power and kWh.
4. Gate — expose the five review checks before trust.
5. Evidence — show the three validation tiers with headline WAPE values.
6. Limits — explain the distance bracket and the untested neighbouring-farm case.
7. Opportunities — state the three next capabilities to build.

## Visual system

- BayWa-inspired primary green `#008C46`, white, charcoal `#333333`, pale green `#E8F3EC`, and amber `#F2B544` for caveats.
- 16:9 layout with a green title/conclusion treatment and light content slides.
- Repeated green square motif, slide number, section label, and bottom progress rail.
- Editable shapes, text, and charts only; no rasterized slide screenshots.
- Use only evidence already present in the repository. Keep limitations explicit and label the BayWa whole-farm/neighbouring-farm scenario as untested.

## Verification

- Extract text from the generated PPTX and check slide order, content, and placeholder text.
- Render to PDF/JPEG and inspect every slide for overflow, low contrast, or collisions.
- Fix any visual issues found, then rerender and recheck.
